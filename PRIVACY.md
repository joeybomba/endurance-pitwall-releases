# Privacy and Data Use

This document explains, in plain language, the main data flows used by Endurance Pitwall.

## iRacing telemetry

Endurance Pitwall reads live race telemetry locally from the running iRacing simulator through the iRacing SDK.

The application does not need your iRacing account password for this local telemetry connection.

## Garage61

Garage61 integration is optional.

If you enable Garage61 functionality, you may provide your own Garage61 API key so Endurance Pitwall can request the Garage61 data needed for those features.

Treat API keys as secrets and do not share them publicly.

## Team sessions

Host, driver, crew and view-only functionality can exchange race-related information with other connected team members.

Depending on the feature being used, this may include:

- Driver names
- Stint information
- Timing and lap information
- Fuel and strategy information
- Team notes
- Team chat
- Session status

Only give team or session access to people you trust.

## Local application data

Endurance Pitwall may store application settings and race-related information locally so features can continue to work between launches.

Protect access to your Windows account and computer as you would for other locally installed software.

## Updates and GitHub

The application or release process may contact GitHub for release or update-related information.

Official downloads are hosted at:

https://github.com/joeybomba/endurance-pitwall-releases/releases

## Advertising and payment

Endurance Pitwall is free and is intended to remain free.

There is no paid feature tier or subscription.

## Third-party services

When you choose to use a third-party integration, that service has its own terms and privacy practices.

Endurance Pitwall is not responsible for the privacy practices of third-party services.

## Changes

If Endurance Pitwall's data handling changes materially, this document should be updated to reflect those changes.
